PostureGuard project and prepare a project approval or funding

About PostureGuard
PostureGuard is a proposed wearable posture-awareness device for
students and developers. The planned prototype uses an ESP32
microcontroller, an MPU6050 motion sensor and a vibration motor. It aims
to monitor the orientation of the wearable and provide a gentle
vibration reminder when a defined condition persists.

Important: The MPU6050 measures the movement and orientation of the
sensor itself. It does not directly measure the posture of the whole
body. Its usefulness depends on sensor placement, calibration and
testing. PostureGuard is intended as a posture-awareness aid, not a
medical or diagnostic device.

How to use this pack
1. Open each Word document and check that the information matches the
   actual project.
2. Update the project status as work progresses.
3. Add your own diagrams, code screenshots, simulation captures and
   photographs.
4. Get current quotations from suppliers and enter the real prices in
   the budget worksheet.
5. Record completed work in the journal with accurate dates and time
   spent.
6. Ask a teacher or technical mentor to review the design and safety
   details.
7. Compare the completed pack with the current official challenge
   instructions before submitting.
Current project status
This pack reflects the following known status at the time it was
prepared:
- The project is at the research and design stage.
- The hardware components have not yet been acquired.
- Physical prototype testing has not yet been completed.
- The circuit design and system architecture still need refinement.
Update these statements when the project genuinely progresses.
Evidence and honesty
- Do not claim that planned work has already been completed.
- Do not present internet reference images as photographs of your own
  prototype.
- Label simulations, reference diagrams and physical tests clearly.
- Do not invent test results, supplier quotations, expenses or
  approvals.
- Keep dated copies of your actual code, design files and test
  records.
Before applying for approval or funding
Check the current official challenge rules for eligibility, deadlines,
required documents, permitted expenses and submission format. Replace
placeholders with accurate information and attach genuine evidence and
supplier quotations.

This pack is an editable preparation resource. It is not an official
application form and does not guarantee approval.
